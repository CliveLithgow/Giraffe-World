Behind the pages

Simple by design.

This site is plain HTML, CSS, and a sprinkle of JavaScript — no framework, no build step. That's on purpose: it makes it a good, low-friction place to test the TinySurveys WebSDK, since there's nothing standing between the embed script and the page.

How it's put together

Four pages, one stylesheet

index.html, giraffes.html, fun-facts.html, and about.html all share styles.css and script.js, so the tab bar and design stay consistent across the site.

No dependencies

Everything renders with just a browser — which means it works straight out of the box on GitHub Pages, with no build tools or servers required.

Where to add the SDK snippet

Open any page's HTML file and paste your TinySurveys embed script just before the closing </body> tag (or in <head>, if that's what your SDK docs call for):

<!-- near the bottom of the page, before </body> -->
<script src="YOUR-TINYSURVEYS-SNIPPET-URL"></script>
<script>
  // any TinySurveys.init(...) config goes here
</script>
